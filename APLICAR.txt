CÓMO SUBIR ESTE TRABAJO (rama + Pull Request)

Ejecuta esto en la raíz de tu clon del repositorio:

  git checkout main
  git pull
  git checkout -b feat/base-auth-chat
  unzip -o ruta/a/duobot-base-auth-chat.zip
  git add -A
  git commit -m "feat: base común de autenticación, roles, MCP con identidad y chat"
  git push -u origin feat/base-auth-chat

Después abre el Pull Request de feat/base-auth-chat hacia main en GitHub.

Nota: el zip no toca README.md. Contiene archivos nuevos y modificados
(servicios, apps, docs/AUTH_Y_CHAT.md y .env.example). Para probar antes de subir:
  cd services/mcp-estudiantes && pip install -r requirements-dev.txt && pytest
