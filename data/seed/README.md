# data/seed

Scripts de descarga y carga (seed) de los datasets de Kaggle a las bases de datos.

- Los CSV completos **no** se suben al repositorio (`data/raw/` está en `.gitignore`).
- Solo se permiten muestras pequeñas con nombre `*.sample.csv`.
- Cada dataset debe documentarse: fuente, licencia, columnas y a qué base va.

Pendiente: elegir datasets (uno por proyecto).
